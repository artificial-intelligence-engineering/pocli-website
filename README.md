# POCLI Website

Official GitHub Pages site for [**POCLI**](https://github.com/artificial-intelligence-engineering/pocli) (*The open-source AI dev team in your terminal — with you as the Product Owner*).

Built with Jekyll 4 and adapted from the MIT-licensed [Jekyll Serif Theme](https://github.com/zerostaticthemes/jekyll-serif-theme).

## Local Development

```bash
bundle install
bundle exec jekyll serve --livereload
```

## Production Build Verification

```bash
JEKYLL_ENV=production bundle exec jekyll build --baseurl "/pocli-website"
```
