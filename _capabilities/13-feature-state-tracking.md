## What It Is

Treats feature progress, lifecycle phases, and deliverable artifact states as first-class structured primitives rather than buried chat prose.

## Why It Matters

Both the human Product Owner and autonomous agents need a single deterministic source of truth for what is specified, implemented, verified, and accepted.

## Implementation Status in POCLI

**Status:** Implemented

Implemented via the 8-phase SDLC state machine (`src/core/workflow.ts`), versioned normative artifacts (`REQ`, `ARCH`, `CODE`, `QA`, `DELIVERY`) in `PoCliDatabase`, and executive HTML status reports generated by `PmReporter` (`src/runtime/pm-reporter.ts`).

### Pending / Roadmap

Granular per-requirement checklist tracking (`REQ-001` → test pass/fail matrix) linked directly to individual git commits.
